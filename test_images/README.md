# Test Images Directory

Place your test photos here for verifying the model (Phase 2):

1. `helmet.jpg` - A clear photo of someone wearing a helmet (similar to how a phone mounted on a two-wheeler handlebar sees the rider).
2. `no_helmet.jpg` - A clear photo of someone not wearing a helmet.
3. `empty.jpg` - A photo of the background or empty scene without any rider.

> **Privacy Note:** Use consenting volunteers only. Never commit private personal photos to public repositories.
